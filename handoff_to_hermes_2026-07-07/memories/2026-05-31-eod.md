## 2026-05-31 全天工作总结

### 1. 左臂 env_cfg.py 修复（重大 bug）

左臂 env_cfg.py 有 6 处从右臂镜像过来的方向性错误：

| Bug | 错误值 | 正确值 |
|-----|--------|--------|
| RIGHT_MID_TARGET_X | `NET_X - half*0.5` = -0.135（左边） | `NET_X + half*0.5` = 1.235（右边） |
| Scene target pos | 硬编码 `NET_X - half*0.5` | `RIGHT_MID_TARGET_X` |
| Obs target pos | 硬编码 `NET_X - half*0.5` | `RIGHT_MID_TARGET_X` |
| 发球 vx 范围 | `(0.7, 2.2)` 向右 | `(-2.2, -0.7)` 向左 |
| predicted_landing target_xy | 硬编码左边 | `RIGHT_MID_TARGET_X` |
| legal_return_separation target_xy | 硬编码左边 | `RIGHT_MID_TARGET_X` |

根因：`_serve_clears_net()` 检查 `vx < -0.05`，但发球 vx 为正 → 全部不通过 → fallback 也不修正 vx → 球向右飞，左臂永远碰不到。

### 3. 从头训练

用右臂完全相同的配置从零训练 2000 轮：成功率 85.7%，compat ~1%。跟右臂 model_2225 一样的结果。

### 4. 关键结论

- compat 信号在单臂训练中极难提升，~1% 是正常水平
- 提升 compat 必然牺牲成功率（trade-off 在 50-55% right / 30% compat 附近平衡）
- **真实 rally 效果必须在双臂合并后评估**，不能只看单臂 compat 指标
- 右臂 model_2225 (84%) 的"视觉完美"回球也是 compat ~1% 水平
