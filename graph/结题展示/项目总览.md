# 基于强化学习的双机械臂乒乓球对打

> 大创项目结题总览 | 哈尔滨工业大学 智能机器人 2023 级

---

## 一、项目目标

让两台 Fairino3 七轴轨道机械臂在 Isaac Sim 仿真环境中学会乒乓球对打——每一个臂都能把球回到对手的舒适区，形成连续回合（rally），而非"各打各的"。

---

## 二、技术栈

| 层次 | 技术 |
|---|---|
| 仿真平台 | NVIDIA Isaac Sim 5.1 + Isaac Lab |
| 强化学习算法 | PPO（Proximal Policy Optimization），RSL-RL 实现 |
| 网络架构 | Actor-Critic，隐藏层 [512, 256, 128]，ELU 激活 |
| 机器人 | Fairino3 六轴机械臂 + Y 轴直线轨道（7-DOF） |
| GPU | NVIDIA RTX 4060 Laptop 8GB |
| 并行环境 | 4096 个并行环境，~80K steps/s |
| 动作空间 | 7 维关节位置控制（rail_y + j1-j6） |
| 观测空间 | 32 维（关节位置/速度、球拍位姿、球位姿、相对向量） |

## 三、核心创新：Opponent-Compatible Reward

这是整个项目最关键的设计。普通"回球成功"reward 只要求球过网，球可能飞到任意位置——对手根本接不到。

### 设计思路

在球过网的瞬间，用 **5 维高斯分布**对球的状态打分：

| 维度 | 含义 | 理想值 | 容忍范围 |
|---|---|---|---|
| y | 横向位置 | 0.0（中间） | ±1.0m |
| z | 高度 | 0.45m | ±0.5m |
| vx | 纵向速度 | 1.5 m/s | ±1.0 |
| vy | 横向速度 | 0.0 | ±1.0 |
| vz | 垂直速度 | 0.15 m/s | ±0.30 |

5 个维度得分相乘 → opponent_compatible 奖励（权重 120）。

### 瓶颈突破

维度诊断发现两个臂的 bottleneck 都在 **vz（垂直速度）**——80% 的回球在这个维度不及格。解决方案：添加独立的 `opponent_vz_quality` 奖励项（权重 30），用更窄的高斯（σ=0.12 vs σ=0.30）给 vz 额外梯度，而不破坏其他维度。

### 直觉类比

不是告诉机械臂"把球打过去就行"，而是"把球打到对手正手位、高度合适、速度舒服"。

## 四、训练历程

### 左臂兼容率演进

| 版本 | Compat Rate | 关键变化 |
|---|---|---|
| v1（基线） | 0.8% | 无 compat reward |
| v2 | 3.3% | 二值→稠密高斯评分 |
| v3 | 6.5% | 权重 40→120 |
| v4-v7 | 8.5%→15.3% | 持续优化 |
| v8 | 15.8% | 接近天花板 |
| **v9** | **17.0%** | 加入 vz_quality term |

### 右臂兼容率演进

| 版本 | Compat Rate | 关键变化 |
|---|---|---|
| v1-v5 | 0.4%→2.3% | reward 不对称，几乎不涨 |
| v6 | **14.8%**（37×） | reward 对齐左臂 |
| v7 | 18.7% | 超越左臂天花板 |
| v8 | 17.6%（回退） | vz³ 重加权导致崩溃 |
| **v9** | **19.5%** | 独立 vz_quality，峰值 |

### 最终结果（v9 合并）

| 指标 | 数值 |
|---|---|
| 左臂 Compat Rate | 17.0% |
| 右臂 Compat Rate | 19.5% |
| Rally > 0（至少一次来回） | **35.3%** |
| Rally ≥ 2（连续两次以上） | 11.6% |
| 最大连续回合 | 4 |
| 平均回合数 | 0.53 |

---

## 五、Rally 方程

```
rally>0 = L_compat × R_compat × chain_factor
35.3%  = 17.0%   × 19.5%    × 10.6
```

理论乘积仅 3.3%，实际 35.3%，**链式放大因子 10.6×**。

这意味着一次好的回球会触发下一次好回球，形成正反馈循环。单臂 compat 的微弱提升在双臂对打中被放大一个数量级——这是支撑整个项目可行性的核心发现。

## 六、从零训练可复现性研究

系统研究训练可复现性，发现并排除了多个隐藏不对称：

| 发现 | 影响 |
|---|---|
| `init_noise_std` 不对称（右 0.2 vs 左 0.7） | 3.5× 探索差异，右臂 0% compat |
| 右臂 reward 权重与左臂不对齐 | v1-v5 停滞 |
| `home_side` 方向性 bug | 球发反方向 |
| 极端种子敏感性（4.4×） | 仅 seed=123 能到 14.5% |

尝试的解决方案及结果：

| 尝试 | 结论 |
|---|---|
| 软门控替代二进制门控 | 差种子微升，好种子崩溃——回退 |
| 加大学习率（1e-3） | 无效，仍陷盆地 |
| 种子切换续训 | 无效，entropy 飙升 |

最终确认：二进制门控是"隐式课程学习"（先过网再优化），非 bug。

---

## 七、关键教训

1. **单臂 compat ≠ 双臂 rally**——从零干净模型（L=24.2%, R=14.5%）rally 仅 19%，不如 v9（L=17.0%, R=19.5%）的 35.3%
2. **独立 reward term > 乘积重加权**——v8 的 vz³ 在 compat 乘积中重加权导致崩溃，v9 的独立 term 才是正解
3. **种子效应 4.4×**——reward landscape 多峰性，只有 seed=123 是甜点
4. **Dense Gaussian > Binary scoring**——v1→v2 的 4× 提升说明稠密信号对梯度至关重要
5. **GPU 并行是关键**——4096 环境并行，~2s/iter，500 iters 仅 17 分钟
